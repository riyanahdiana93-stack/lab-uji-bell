# Lab Virtual Uji Bell

Simulasi interaktif berbahasa Indonesia tentang keterbelitan kuantum, uji Bell (ketaksamaan CHSH), celah eksperimen, dan teleportasi kuantum. Dibuat sebagai bahan ajar untuk mahasiswa S1 Fisika, berdasarkan eksperimen peraih Nobel Fisika 2022 (Clauser, Aspect, Zeilinger).

Projek mata kuliah Fisika Modern Lanjutan, Magister Pendidikan Fisika, FMIPA Universitas Negeri Jakarta, 2026.

## Isi
- **Eksperimen**: atur sudut polarisator, visibilitas p, efisiensi detektor η, lalu cacah koinsidensi.
- **Kurva E(θ)**: bandingkan data dengan prediksi mekanika kuantum dan model variabel tersembunyi lokal.
- **Uji CHSH**: hitung parameter S untuk kedua model.
- **Teleportasi**: protokol tiga qubit, dengan dan tanpa kanal klasik.
- **Lembar kegiatan**: 9 kegiatan terarah dan catatan untuk pengajar.
